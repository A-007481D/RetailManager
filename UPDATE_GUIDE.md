# Guide de Mise à Jour et Sauvegarde - RetailManager

## 💾 Nouvelle Fonctionnalité de Sauvegarde (v1.1.0+)

Pour éviter toute perte de données lors des mises à jour ou en cas de problème technique, nous avons ajouté une fonctionnalité de **Sauvegarde**.

### Comment Sauvegarder Vos Données ?
1. Ouvrez l'application **RetailManager**.
2. Allez sur le **Tableau de Bord** (écran d'accueil).
3. Cliquez sur le bouton vert **"Sauvegarder"** en haut à droite.
4. Choisissez l'emplacement où vous souhaitez enregistrer le fichier (par exemple : `Documents`, `Clé USB`, `Google Drive`).
5. Cliquez sur **Enregistrer**.

Un message de confirmation apparaîtra si la sauvegarde est réussie.

---

## 🔄 Comment Mettre à Jour l'Application

### 1. Sauvegardez d'abord !
Avant toute mise à jour, il est recommandé d'utiliser le bouton "Sauvegarder" comme décrit ci-dessus.

### 2. Télécharger la Nouvelle Version
Téléchargez le nouvel installateur fourni par votre développeur.

### 3. Installer
Lancez l'installateur. Il détectera automatiquement votre installation existante.
 Vos données (clients, factures, produits) **ne seront PAS supprimées**. Elles sont stockées dans un dossier sécurisé séparé du programme.

### 4. Vérifier
Après l'installation, lancez l'application et vérifiez que vos dernières factures sont présentes.

---

## ❓ En Cas de Problème

Si vous rencontrez un problème après une mise à jour :
1. **Ne paniquez pas**, vos données sont probablement toujours là.
2. Si vous avez fait une sauvegarde, vous pouvez restaurer le fichier `invoices.db`.
3. Contactez le support technique avec le fichier de sauvegarde.
